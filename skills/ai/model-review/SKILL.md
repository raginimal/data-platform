# Model Review Skill

- Skill ID: `AI-SK-001`
- Version: `1.0.0`
- Owner: AI owner placeholder
- Applicable policies: `AI-001`, `AI-002`, `AI-MOD-001` through `AI-MOD-004`

## Purpose
Review model identity, approval, configuration, risk, provider/data boundary, monitoring, cost, and rollback.

## When to run
Run for model configuration, provider, version, embeddings, inference, or model-serving changes.

## Inputs
Model configuration, intended use, data classification, evaluation evidence, provider terms, and PR context.

## Analysis procedure
Check approved model/version, ownership, permitted data, risk assessment, evaluation suite, monitoring, cost limits, and human oversight.

## Expected output
Use the shared finding contract with `AI-*` policy IDs and separate evidence from recommendations.

## Human review
AI, security, data, and risk owners approve material model changes and exceptions.
