# ADR Review Skill

- Skill ID: `ARCH-SK-003`
- Version: `1.0.0`
- Owner: architecture owner placeholder
- Applicable policies: `ARCH-007`, `RP-005`, `DEVOPS-PR-003`

## Purpose
Determine whether a change needs an ADR and assess whether its decision, alternatives, consequences, and controls are documented.

## When to run
Run for new services, platforms, stores, boundaries, public APIs, AI platforms, security exceptions, or major operational decisions.

## Inputs
Changed files, PR description, architecture documents, ADR directory, and applicable policies.

## Analysis procedure
Identify ADR triggers, check the decision record for context and alternatives, and verify consequences, ownership, automation, and review status.

## Expected output
Report missing or incomplete ADR evidence using the shared finding contract.

## Human review
Architecture owners determine whether an ADR is sufficient and approve material decisions.
