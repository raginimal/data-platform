# Architecture Policies

Normative architecture rules are defined in:

- `architecture-principles.md` for boundaries, APIs, resilience, observability, IaC, and ADR triggers.
- `dependency-principles.md` for dependency purpose, provenance, vulnerability, licensing, and boundary risk.

Add a rule when a repeated architecture issue should become a stable, testable control. Record exceptions with `docs/adr/exception-template.md` and obtain human approval.
