# DevOps Policies

Normative delivery rules are defined in:

- `branching.md`
- `pull-request.md`
- `ci-principles.md`
- `cd-principles.md`
- `release-management.md`
- `environment-management.md`

These documents define the lifecycle from issue through production and identify future enforcement candidates. Exceptions require a human approver and an expiry or review date.
