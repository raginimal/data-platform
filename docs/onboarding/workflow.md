# Feature Workflow

```text
Developer
  -> feature branch
  -> develop with approved AI assistance
  -> bash scripts/check.sh
  -> commit and push
  -> Pull Request
  -> Build, Quality, Security, Architecture, Governance
  -> advisory Architecture, Security, DevOps, AI Engineering review
  -> CODEOWNER review
  -> merge queue
  -> protected main
  -> artifact
  -> DEV
  -> automated validation
  -> TEST/UAT
  -> human approval
  -> PROD
```
